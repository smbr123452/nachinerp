# SIRIUS AURUM ERP — дизайн систем

Энэ баримт нь интерфэйсийн НЭГДСЭН дүрмийг тогтооно. Шинэ дэлгэц нэмэхдээ
эндээс токен, бүрдлээ сонгоно — гараар шинэ хэмжээ, өнгө зохиохгүй.

Хэрэгжилт: `tailwind.config.ts` (токен), `src/components/ui/*` (бүрдэл),
`src/app/globals.css` (суурь).

---

## 1. Өнгө

Систем нь ЗӨВХӨН таван бүлэг өнгө хэрэглэнэ. Шинэ бүлэг нэмэхгүй.

| Бүлэг | Утга | Хэрэглээ |
|---|---|---|
| `ink` | Саармаг | Текст, хүрээ, дэвсгэр |
| `brand` | Үндсэн цэнхэр | Үйлдэл, идэвхтэй төлөв, онцлох утга |
| `emerald` | Эерэг | Ашиг, батлагдсан, өсөлт |
| `red` | Сөрөг / эргэлт буцалтгүй | Алдаа, устгах, алдагдал |
| `amber` | Анхааруулга | Хүлээгдэж буй, дутагдалтай |

**Дүрэм.** Улаан өнгийг зөвхөн (а) алдаа, (б) эргэлт буцалтгүй үйлдлийн
дүрс тэмдэг ба эцсийн товч, (в) сөрөг санхүүгийн утгад хэрэглэнэ. Бүхэл
хэсгийг улаанаар будахгүй.

**Домэйны онцгой тохиолдол.** Актын (`InventoryWriteOff`) POSTED төлөв нь
БАТЛАГДСАН хорогдол тул улаанаар харагдана (`countsAsLoss`). Энэ нь
худалдан авалтын POSTED (ногоон) -оос ЗОРИУДААР ялгаатай — нэгтгэхгүй.

## 2. Үсгийн хэмжээ

`tailwind.config.ts` дотор нэрлэгдсэн токен. Дурын `text-[13px]` мэт утга
бичихгүй.

| Токен | Хэмжээ / мөр | Хэрэглээ |
|---|---|---|
| `text-meta` | 11 / 16 | Хүснэгтийн толгой, шошго, бүлгийн нэр |
| `text-caption` | 12 / 18 | Тайлбар, сануулга, туслах тэмдэглэл |
| `text-body` | 13 / 20 | **Интерфэйсийн үндсэн текст** |
| `text-title` | 15 / 24 | Хайрцаг, хэсгийн гарчиг |
| `text-figure` | 19 / 28 | Формын онцолсон дүн |
| `text-page-title` | 22 / 32 | Хуудасны гарчиг (`PageHeader`) |
| `text-display` | 30 / 40 | Нэвтрэх хуудасны гарчиг |
| `text-kpi-sm` / `text-kpi` | 22 / 28 | Үзүүлэлтийн тоо (`StatCard`) |

Онцгой: `SiriusAurumLockup` нь лого доторх оптик тохируулгатай тул өөрийн
хэмжээг хадгална. `BarChart`-ын 10px шошго нь зурагт таарахаар сонгогдсон.

Фонт: **Inter** (кирилл + латин), `--font-inter` хувьсагчаар.

## 3. Зай

- Хуудасны блок хоорондын зай: `mb-4` (16px)
- Сүлжээний завсар: `gap-3` (12px)
- Гадаргуугийн дотоод зай:
  - нягт (хүснэгтийн нүд): `px-4 py-2.5`
  - энгийн (шүүлтүүр, жагсаалтын мөр): `px-4 py-3`
  - уужим (хайрцгийн толгой ба их бие): `px-5 py-4`

## 4. Радиус ба сүүдэр

| Токен | Утга | Хэрэглээ |
|---|---|---|
| `rounded-md` | 6px | Жижиг тэмдэглэгээ, дүрсний хайрцаг |
| `rounded-lg` | 8px | Товч, оролт, цэсний мөр |
| `rounded-card` | 10px | Хайрцаг, самбар |
| `rounded-xl` | 12px | Модал |
| `shadow-card` | — | Хайрцгийн суурь өргөлт |
| `shadow-pop` | — | Модал, унждаг цэс |

## 5. Товчны шатлал

| Хувилбар | Хэрэглээ |
|---|---|
| `primary` | Хуудасны гол үйлдэл. Нэг дэлгэцэд нэг л удаа |
| `secondary` | Хоёрдогч үйлдэл |
| `ghost` | Хүснэгтийн мөр доторх жижиг үйлдэл |
| `danger` | Эргэлт буцалтгүй үйлдлийг НЭЭХ товч (зөөлөн улаан) |
| `dangerSolid` | Баталгаажуулах модал доторх ЭЦСИЙН устгах / цуцлах товч |
| `link` | Текстэн холбоос |

Хэмжээ: `sm` (h-8) хүснэгтэд, `md` (h-9) анхдагч, `lg` (h-11) формын
эцсийн үйлдэлд.

Холбоосыг товч шиг харуулах шаардлагатай бол `buttonClass()`-ыг ашиглана —
ангиллын мөрийг гараар хуулбарлахгүй.

## 6. Оролт ба форм

Бүх оролт `CONTROL` + `CONTROL_HEIGHT` токеныг хуваалцана
(`components/ui/Field.tsx`): ижил өндөр (h-9), ижил радиус, ижил фокус.
`SearchableCombobox` мөн адил токеныг хэрэглэнэ.

- Талбарын бүтэц: `<Field label htmlFor required error hint>` дотор оролт.
- Талбаруудыг `<FieldGrid columns>` -оор байрлуулна.
- Алдааг талбарын доор улаан текстээр, `hint`-ийг орлуулж харуулна.

## 7. Хүснэгт

- Бүх хүснэгт `components/ui/Table.tsx`-ийн бүрдлийг ашиглана. Түүхий
  `<table>` бичихгүй — хэвтээ гүйлгэлт хайрцгийн дотор л явагдана.
- Тоон багана `align="right"` (автоматаар `tabular` тоо).
- Хоосон хүснэгт `EmptyRow`, хоосон бүхэл дэлгэц `EmptyState`.

## 8. Төлөвүүд

Бүрдэл бүр дараах төлөвүүдийг хангана.

| Төлөв | Хэрэгжилт |
|---|---|
| Анхдагч | — |
| Hover | `hover:` өнгө |
| Focus | Дэлхий нийтийн `:focus-visible` (globals.css) — 2px ring |
| Disabled | `disabled:` бүдгэрэлт + `cursor-not-allowed` |
| Loading | `SubmitButton` (`useFormStatus`), `pendingText`-тэй |
| Хоосон | `EmptyRow` / `EmptyState` |
| Алдаа | `Alert tone="error"` эсвэл `Field error` |

### Хуудасны түвшний төлөв

| Файл | Үүрэг |
|---|---|
| `(app)/loading.tsx` | Шилжилтийн орлуулагч (`PageSkeleton`) |
| `(app)/not-found.tsx` | Олдоогүй бичлэг — системийн хэл, гарцтай |
| `(app)/error.tsx` | Алдааны хамгаалалт — дахин оролдох + дугаар |

## 9. Баталгаажуулах модал

Эргэлт буцалтгүй бүх үйлдэл `ConfirmDialog`-оор явна: улаан дүрс тэмдэг,
саармаг гарчиг, зүүн талд `Болих`, баруун талд `dangerSolid` товч.
Гарчгийг улаанаар будахгүй.

## 10. Хөндөхгүй зүйлс

Дизайн систем нь ЗӨВХӨН харагдацыг зохицуулна. Дараахыг өөрчлөхгүй:
бизнес логик, Prisma схем, server action, эрхийн шалгалт, маршрут,
навигацийн бүтэц, `SearchableCombobox`-ийн ажиллагаа.
