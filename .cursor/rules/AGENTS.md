# Project Instructions

This is an internal ERP system for food production, warehouse, branches, and delivery.

## Stack
- Next.js
- TypeScript
- PostgreSQL
- Prisma
- Tailwind

## Rules
- Plan before coding
- Keep modules separate
- Do not break existing code
- Use Mongolian UI
- Add audit logs for important actions

## Core modules
- Users and roles
- Branches
- Warehouses
- Raw materials
- Finished products
- Stock movements
- Transfers
- Audit logs
